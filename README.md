# 📦 Inventory Management System

A web-based Inventory Management System built with 
Python, Flask, SQLite, HTML & Bootstrap.

## 🚀 Features
- ➕ Add new products
- 📋 View all products in a table
- 🔍 Search by name or category
- ✏️ Edit product details
- 🗑️ Delete products with confirmation
- ⚠️ Low stock alert (quantity below 10)

## 🛠️ Tech Stack
| Layer    | Technology        |
|----------|-------------------|
| Backend  | Python + Flask    |
| Database | SQLite            |
| Frontend | HTML + Bootstrap  |
| Language | Python 3.x        |

## ⚙️ How to Run

1. Clone the repository
   git clone https://github.com/ahmedraza-shaikh/Inventory-Management-System.git

2. Install Flask
   pip install flask

3. Run the app
   py app.py

4. Open browser and go to
   http://127.0.0.1:5000
